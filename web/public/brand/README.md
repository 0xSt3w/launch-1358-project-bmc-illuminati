# Official brand images

The brief names two owner-provided files. They were not included with this
assignment, so the site renders a code-drawn vector emblem until they arrive.

Drop the official files here with exactly these names and rebuild:

- `bmc.jpg` — purple/blue BMC triangle-eye logo (header, navigation, token and staking sections)
- `bmc-imd.png` — glowing green pyramid (home hero, ecosystem backgrounds)

Then set `officialImages: true` in `src/config/brand.ts`. No other change is needed.
